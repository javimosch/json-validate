# json-validate
CLI utility. Written in Go.
```bash
curl -LO https://github.com/javimosch/json-validate/releases/latest/download/json-validate-linux-amd64
chmod +x json-validate-linux-amd64; sudo mv json-validate-linux-amd64 /usr/local/bin/json-validate
```

---

This tool is a plugin for [supercli](https://github.com/javimosch/supercli) — an AI-friendly, config-driven dynamic CLI platform.
